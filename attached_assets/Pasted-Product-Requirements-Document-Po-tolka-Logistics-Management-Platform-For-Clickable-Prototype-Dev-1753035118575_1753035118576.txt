Product Requirements Document
Poštolka - Logistics Management Platform
For Clickable Prototype Development

Product Overview
Product Name: Poštolka
Product Type: Logistics Management Web Application
Target Users: MSC Agents & Medlog CUS (200 internal users)
Purpose: Replace legacy Power Apps for container transport management

Core User Stories
Primary User: MSC Agent / Medlog CUS
"As a logistics coordinator, I need to manage container shipments efficiently so that I can process orders quickly and track their status in real-time."

Key Jobs to be Done:
Browse Orders: View list of all BL/bookings with key information
Filter & Search: Find specific shipments using multiple criteria
View Details: Access complete BL information on separate screen
Track Changes: See what's new/changed since last login
Process Orders: Create, edit, and approve import/export orders

User Flows
Flow 1: Browse and View BL Details
Land on Screen 1 → See BL list table
Scan visually → Notice priority indicators and status colors
Click BL number → Navigate to Screen 2 (BL Detail)
Review details → See complete booking information
Use back button → Return to Screen 1
Flow 2: Filter and Find Specific BL
Start on Screen 1 → See full BL list
Type in Client filter → "Škoda Auto"
Add ETA filter → Select date range
Apply filters → See filtered results
Click relevant BL → Go to Screen 2
Flow 3: Monitor Daily Operations
Login to Screen 1 → See today's shipments
Check priority indicators → Notice red/orange items
Click high-priority BL → Open Screen 2
Review container status → Check for issues
Add notes if needed → Use Notes tab
Return to list → Continue monitoring
Flow 4: Container Management
Navigate to Screen 2 → From BL click
Review container table → Check all containers
Click container row → Expand for details
Update status → Use action buttons
Add new container → Use + Add button

Data Models
typescript
interface BLSummary {
  blNumber: string;
  date: string;
  client: string;
  consignee: string;
  destination: string;
  containerCount: number;
  type: 'Import' | 'Export';
  carrier?: string;
  status: 'Draft' | 'In Progress' | 'Delivered' | 'Issues';
  priority: 'high' | 'medium' | 'low';
  hasChanges: boolean;
}

interface BLDetail {
  blNumber: string;
  customerRef: string;
  jobType: 'Import' | 'Export';
  status: string;
  customer: CustomerInfo;
  vessel: VesselInfo;
  delivery: DeliveryInfo;
  containers: Container[];
}

interface Container {
  jobNumber: string;
  containerNumber: string;
  size: string;
  weight: number;
  routeInfo: RouteStep[];
  status: string;
  sealNumber?: string;
  temperature?: number;
}
